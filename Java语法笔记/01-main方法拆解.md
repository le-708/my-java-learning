public 公共的，大家都能访问

static 这个东西（方法或变量）属于“类”本身，而不属于任何一个具体的“对象”，在刚刚创建还没有任何对象被创建时，main 方法必须是static的，才能不依赖对象，直接被调用

void  空的，没有返回值，程序结束就结束了

main 是Java语法规定的程序入口名字，JVM只认这个名字，它是这个“约定好的，特殊的”方法名

String\[] args 是一个参数声明，String\[] 表示一个“能装很多字符串的数组”，args是这个数组的变量名。在命令行java TestMain苹果，香蕉里敲的那些单词，JVM会把他们打包成一个数组，交给写在main方法里的args变量
