1\.基本数据类型和引用数据类型的区别是什么？

基本类型变量存的是值本身，引用类型变量存的是对象在内存中的地址。赋值时，基本类型复制值，引用类型复制地址。所以两个引用变量指向同一个对象时，通过任何一个变量修改对象内容，另一个变量看到的也会变



2\.为什么实验2里 arr1\[0]被改变了？

arr2 = arr1 把 arr1 存的地址复制给了 arr2，两者指向内存中同一个数组对象。通过 arr2\[0] 修改的，是那个唯一的数组，arr1 再去读当然也变了。



3.String是引用数据类型，但为什么实验3里s1没变？

String 是 Java 里特殊的不可变对象。s2 = "world" 并不是修改了原来的字符串内容，而是让 s2 重新指向了一个新的字符串对象。s1 仍然指向原来的 "hello"，所以不受影响。
